# Пересборка субтитров и цветокор для видеоуроков

Делает из урока в `video-lessons/` новую копию в `video-lessons-remastered/`:
заново распознанные субтитры с грамотным переносом строк поверх матовой плашки,
скрывающей старые вшитые титры, плюс мягкий beauty-грейд.

**Исходники не изменяются** — пайплайн открывает `video-lessons/` только на чтение.

## Зачем

Старые субтитры вшиты в картинку, отдельного трека в контейнере нет. При этом
они собраны не по смыслу, а по паузам VAD, поэтому строка обрывается на запятой,
а иногда и посреди слова («…количество пространства заполняемо / е пигментом»).
Замер `scripts/promo/output/pigmenty/transcript.json`:

| Метрика | Было | Норма | Стало |
|---|---|---|---|
| Символов в реплике, максимум | 163 | ≤ 77 | 76 |
| Длительность, максимум | 36.5 с | ≤ 6 с | 5.6 с |
| Скорость чтения, максимум | 61.5 симв/с | ≤ 17 | 20.5 |
| Дублей-галлюцинаций | есть | нет | нет |

## Установка

```powershell
cd scripts/subtitles
uv venv --python 3.12 .venv          # CTranslate2 не собирается под 3.14
uv pip install --python .venv/Scripts/python.exe -r requirements.txt
```

Нужен `ffmpeg` с `libass` в PATH. GPU подхватывается сам: CUDA-библиотеки едут
в колёсах `nvidia-cublas-cu12` и `nvidia-cudnn-cu12`, при их отсутствии
распознавание уходит на CPU.

## Работа

```powershell
# полный прогон одного урока (~25-30 мин для 13 мин видео)
.\.venv\Scripts\python.exe run_lesson.py --lesson pigmenty

# правите video-lessons-remastered/pigmenty/subs/pigmenty.srt в любом редакторе

# быстрая переотрисовка из отредактированного .srt (~6-8 мин)
.\.venv\Scripts\python.exe run_lesson.py --lesson pigmenty --rerender-subs
```

Рендер разбит на два прохода. Проход A собирает `*.master.mp4` — цветокор и
плашка, но без текста. Проход B вжигает `.ass` в этот мастер. Поэтому правка
субтитров не требует пересчёта грейда и повторного распознавания.

`.srt` — ведущий файл: `.ass` всегда пересобирается из него, и строки
переразбиваются заново, так что ручная правка не нарушит лимиты по длине.
Ключ `--keep-ass` отключает регенерацию, если нужна точечная стилевая правка.

### Ключи

| Ключ | Что делает |
|---|---|
| `--rerender-subs` | только проход B из отредактированного `.srt` |
| `--keep-ass` | не пересобирать `.ass` из `.srt` |
| `--encoder nvenc` | кодировать на GPU (быстрее, качество близкое) |
| `--grade-strength 0.5` | ослабить цветокор (0 — выключить) |
| `--sample 90` | собрать только первые 90 секунд, для проб |
| `--no-cuts` | не искать монтажные склейки |
| `--all` | прогнать все уроки курса по порядку, пропуская готовые |
| `--redo` | с `--all`: пересобирать и уже готовые |
| `--subs-only` | остановиться после сборки субтитров, не кодировать видео |
| `--force-asr` | распознать заново, игнорируя кеш |
| `--force-master` | пересобрать мастер (цветокор и плашку) |
| `--corrector gemini\|openai` | дополнительная правка текста моделью поверх глоссария |
| `--karaoke soft\|brand` | подсветка по словам синхронно с речью |

### Караоке-подсветка

`--karaoke soft` подсвечивает слова синхронно с речью: прозвучавшее — плотный
белый, впереди — приглушённый серый, заливка идёт плавно внутри слова. Опирается
на пословные таймкоды из `subs/*.words.json`, поэтому дополнительных проходов
распознавания не требует. Вариант `brand` заливает розовым брендовым цветом.

Приглушение задано **цветом**, а не прозрачностью: `\fad` управляет альфой всей
строки и на входе-выходе смазал бы разницу между прозвучавшим и предстоящим.

Две вещи, без которых караоке разъезжается с голосом, — обе проверены на рендере
покадрово:

- **Караоке-часы стартуют с начала реплики, а не с первого слова.** Титр
  появляется на 0.08 с раньше речи, плюс граница могла отъехать из-за зазора до
  соседней реплики. На первой реплике урока это 0.47 с — заливка убегала вперёд
  на два слова. Зазор выносится в пустой тег `\k`.
- **Паузы между словами тоже выносятся в пустые теги.** Иначе заливка
  размазывается по молчанию и к концу фразы копит отставание.

Границы слов дополнительно прижимаются к границам реплики: у последнего слова
конец лежит за её пределами, и без этого заливка не успевала дойти до конца
строки перед исчезновением.

Если пословных таймкодов для реплики нет или их число не совпало со словами в
строках, реплика молча рисуется обычной — счётчик таких случаев пишется
комментарием в шапку `.ass`.

`.srt` остаётся без караоке: формат его не поддерживает. Это и нужно — сайдкар
для Kinescope должен быть простым текстом.

### Правка текста моделью

Глоссарий чинит искажения известных терминов, но не видит подмену обычного слова
похожим по звучанию («которую мы для себя *придерели*» вместо «определили») —
это ловится только по смыслу. Такой проход включается `--corrector gemini` или
`--corrector openai` и требует рабочего ключа в корневом `.env`
(`GEMINI_API_KEY` / `OPENAI_API_KEY`).

Модель работает под жёсткими рамками: порядок слов не менять, не перефразировать,
фраз не объединять. Правка со схожестью ниже 0.6 или разросшаяся больше чем в
1.35 раза отбрасывается, остаётся оригинал. Таймкоды возвращаются словам
выравниванием последовательностей — совпавшие слова сохраняют своё время,
вставленные получают его пропорционально длине, не наезжая на соседей.

Без ключа проход просто пропускается с сообщением в лог; текст остаётся после
детерминированного слоя.

## Проверка

```powershell
.\.venv\Scripts\python.exe selftest.py
```

Проверяет инварианты без обращения к видео и сети: перенос строк,
неприкосновенность настоящих русских слов, возврат таймкодов после правки,
round-trip через `.srt`, лимиты реплик.

## Весь курс

Кодирование всего курса (4.5 часа видео) занимает около 8 часов на x264 slow, поэтому
порядок такой: сначала дешёвые шаги по всем урокам, проверка, и только потом рендер.

```powershell
# 1. распознавание и субтитры по всем урокам (~1-1.5 ч), без кодирования
.\.venv\Scripts\python.exe run_lesson.py --all --karaoke soft --subs-only

# 2. просмотреть qa/cue-stats.txt и qa/band-detect.png у каждого урока

# 3. рендер (~8 ч; с --encoder nvenc примерно 2 ч)
.\.venv\Scripts\python.exe run_lesson.py --all --karaoke soft
```

Каждый шаг кеширован: распознавание, полоса, склейки, замер цветокора и мастер
переиспользуются, поэтому второй запуск не пересчитывает первый. Урок считается
готовым по наличию финального mp4 (или `.srt` в режиме `--subs-only`) и
пропускается; `--redo` заставляет пересобрать.

Батч не останавливается на ошибке одного урока — в конце печатается сводка со
статусом и временем по каждому.

**Штатная остановка.** Создайте файл `video-lessons-remastered/STOP` — батч
доработает текущий урок и остановится на границе, а не посреди кодирования.
Флаг проверяется между уроками и снимается автоматически. Убивать процесс не
нужно: прерванный ffmpeg оставляет обрезанный mp4, который следующий запуск
примет за готовый урок и пропустит.

## Что получается

```
video-lessons-remastered/pigmenty/
  пигменты-720p.mp4          финал
  пигменты-720p.master.mp4   мастер без текста (для быстрой переотрисовки)
  subs/  pigmenty.srt        ← правится руками
         pigmenty.ass        генерируется из .srt
         pigmenty.cues.json  реплики со строками
         pigmenty.words.json словные таймкоды
  qa/    band-detect.png     где нашлась полоса старых титров
         grade-ab.png        цветокор до/после
         final-stills.png    стоп-кадры финала
         preview-60s.mp4     минута для просмотра
         cue-stats.txt       метрики было/стало и нарушения стандарта
         corrections.diff.txt что поправил глоссарий
  render.json                все параметры прогона
```

`.srt` годится и для загрузки в Kinescope отключаемой дорожкой — тогда у зрителя
появится выбор, а вшитый вариант останется фолбэком.

## Модули

| Файл | Ответственность |
|---|---|
| `run_lesson.py` | оркестратор, кеширование шагов, отчёты |
| `detect_band.py` | измеряет полосу старых титров по кадрам |
| `transcribe_words.py` | faster-whisper large-v3 со словными таймкодами |
| `correct_text.py` | глоссарий + морфология: правка терминов |
| `segment_cues.py` | сборка реплик и перенос строк по-русски |
| `build_ass.py` | `.ass` и `.srt`, парсер отредактированного `.srt` |
| `grade.py` | замер картинки и построение цветокора |
| `render.py` | ffmpeg: два прохода, маски, кодек |
| `llm_polish.py` | необязательная правка текста моделью с возвратом таймкодов |
| `selftest.py` | проверка инвариантов без видео и сети |

Карта уроков не дублируется — берётся из
[`scripts/promo/catalog.py`](../promo/catalog.py).

## Тонкости, на которые ушло время

- **Позиция полосы измеряется, а не задаётся.** Порог берётся по доле кадров, а
  не по доле от максимума: вторая строка субтитров встречается реже первой и при
  относительном пороге отсекалась — нижний край полосы обрезался ровно там, где
  живёт перенос.
- **Пунктуацию нельзя терять.** В faster-whisper `initial_prompt` действует
  только на первое окно, поэтому `condition_on_previous_text=False` оставляет
  модель без контекста и она перестаёт ставить знаки — а на них держится вся
  разбивка. Контекст сохраняем, петли давим `repetition_penalty`,
  `prompt_reset_on_temperature` и порогом на тишину.
- **Правится только слово, которого нет в словаре русского.** Без этого
  предохранителя нечёткое сопоставление разносит текст: на корпусе уроков оно
  39 раз меняло «покрываем» на «перекрываем» и 29 раз «сразу» на «страз».
- **Дробление реплики не снижает скорость чтения** — делятся и текст, и время.
  CPS лечится растягиванием в соседнюю паузу; остаток — это темп речи.
- **`colorlevels` в ffmpeg 8.1 рушит 10-битный вход** (проверено покадрово:
  R=0.1 G=0.0 B=38 против R=107 G=103 B=132). Точки чёрного/белого и баланс
  белого сведены в `curves`.
- **Баланс белого — по светлым нейтральным пикселям, не по среднему кадра.**
  Кадр занимают фиолетовые перчатки, и по среднему выходит несуществующий
  избыток синего.
- **Размывается весь кадр, подставляется только низ по маске.** Если размывать
  вырезанную полосу, её цвет у кромки перестаёт совпадать с картинкой выше и
  стык виден как проведённая линия. Растушёвка идёт выше полосы — внутри она
  ослабила бы размытие ровно там, где лежит старый текст.
