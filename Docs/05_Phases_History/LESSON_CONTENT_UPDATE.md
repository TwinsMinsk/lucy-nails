# Обновление функционала уроков: Конспекты (Rich Text)

Добавлена возможность создания и отображения форматированного текстового описания (конспекта) для каждого урока.

## Что сделано:

### 1. Backend & Database
- В модель `Lesson` добавлено поле `content` (тип Text).
- Обновлены Pydantic-схемы для приема и возврата `content`.
- Создана и применена миграция Alembic.
- Добавлен новый эндпоинт `GET /api/admin/lessons/{lesson_id}` для получения полных данных урока в админке.

### 2. Admin Panel (WYSIWYG Редактор)
- Установлены зависимости `Tiptap` для реализации редактора.
- Создан новый UI-компонент `frontend/src/components/ui/editor.tsx`.
- Поддерживается форматирование: Жирный, Курсив, Подчеркивание, Заголовки (H1, H2), Списки (маркированный, нумерованный), Цитаты.
- Редактор интегрирован в диалоговое окно редактирования урока. При открытии редактирования данные урока теперь подгружаются динамически.

### 3. Отображение (User View)
- Установлен и настроен плагин `@tailwindcss/typography` для красивого рендеринга HTML-контента.
- Страница урока (`app/(protected)/courses/[id]/lessons/[lessonId]/page.tsx`) теперь отображает поле `lesson.content` в специальном блоке "Конспект урока" под видеоплеером.
- Убраны моковые данные для основного контента урока, теперь он загружается из API.

## Инструкции по использованию:
1. Перейдите в админ-панель -> Курс -> Редактировать урок.
2. В поле "Конспект" напишите текст и отформатируйте его с помощью панели инструментов.
3. Сохраните изменения.
4. Откройте урок как студент — под видео появится ваш текст.
