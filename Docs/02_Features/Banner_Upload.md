# Инструкция по загрузке баннеров курсов

## Обзор

Функция загрузки баннеров позволяет администраторам загружать изображения обложек курсов двумя способами:
1. **URL**: Ввести прямую ссылку на изображение
2. **Загрузка файла**: Загрузить изображение напрямую с компьютера

## Использование в админ-панели

### Создание/Редактирование курса

1. Откройте админ-панель → "Управление курсами"
2. Нажмите "Добавить курс" или "Редактировать" существующий курс
3. В поле "Баннер (обложка)" вы можете:
   - **Вариант 1**: Вставить URL внешнего изображения
   - **Вариант 2**: Нажать "Выбрать файл" и загрузить изображение с компьютера
4. После загрузки файла появится превью изображения
5. Сохраните курс

### Поддерживаемые форматы

- JPG/JPEG
- PNG
- WebP
- GIF

Максимальный размер файла определяется настройками сервера.

## Техническая информация

### Backend

**Endpoint**: `POST /api/admin/upload`

**Требования**: 
- Роль администратора
- Multipart/form-data

**Ответ**:
```json
{
  "url": "/uploads/abc123.jpg",
  "filename": "abc123.jpg"
}
```

### Хранение файлов

Загруженные файлы сохраняются в:
```
frontend/public/uploads/
```

Файлы доступны через URL: `http://localhost:3000/uploads/filename.jpg`

### Frontend API

```typescript
import { adminUploadFile } from "@/lib/api";

const file = e.target.files[0];
const result = await adminUploadFile(file);
console.log(result.url); // "/uploads/abc123.jpg"
```

## Безопасность

1. Загрузка доступна только администраторам
2. Проверка расширений файлов на стороне сервера
3. Генерация уникальных имен файлов (UUID)
4. Директория uploads не индексируется в Git

## Отображение баннеров

Баннеры автоматически отображаются:
- В личном кабинете студента (карточки курсов)
- На главной странице (если курс опубликован)

Если баннер не указан, отображается заглушка с иконкой книги.
