# Календарь публикаций — кампания «Время расти»

Старт — понедельник 9 ноября 2026, две недели по три ролика. Ролики озвучены нейросетью (Gemini TTS
«Sulafat», `ads/audio/tts.py`), как и в кампании «За дизайн доплачивают». Время — 19:30 МСК, через
неделю сверить с Instagram: «Профессиональная панель → Аудитория → Самое активное время».

Публикуем органически в своём аккаунте, без кнопки «Продвигать» (реклама в Instagram в РФ запрещена
с 01.09.2025). Те же ролики подходят для VK Клипов.

## Как тестируем хуки (неделя 1)

Для R11 и R12 есть три начала: A (основное), B и C. Остальной ролик одинаковый.

1. В день публикации все три варианта выкладываются как **«Пробные Reels»**: их видят только те, кто на вас
   не подписан.
2. Через 48 часов сравниваем **удержание в первые 3 секунды** и **среднее время просмотра**.
3. Победителя публикуем для подписчиков («Поделиться с подписчиками» в пробном ролике), двух других
   оставляем пробными.
